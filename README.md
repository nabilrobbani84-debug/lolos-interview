# InterviewReady - Platform Simulasi Interview Kerja Interactive & Modern

> **Tagline:** Latihan Interview, Tingkatkan Percaya Diri, Raih Pekerjaan Impian.

InterviewReady adalah platform simulasi wawancara kerja berbasis web yang interaktif, profesional, dan kaya fitur. Platform ini dirancang untuk membantu pelajar SMK, mahasiswa, fresh graduate, pencari kerja, dan profesional dalam mengasah kemampuan interview berdasarkan bidang pekerjaan, posisi spesifik, tingkat pengalaman, bahasa, dan tingkat kesulitan.

---

## 🌟 Fitur Utama

- **12+ Bidang & 40+ Posisi Pekerjaan**: Mencakup IT, Desain, Marketing, Bisnis, Keuangan, HR, Sales, Teknik, Pendidikan, Kesehatan, Hukum, Perhotelan, hingga Interview Umum.
- **Simulasi Realistis (Teks & Suara)**: Simulasi interview interaktif dengan Pewawancara Virtual (Interviewer Avatar), timer real-time, perekam suara, dan transkripsi.
- **Engine Evaluasi Otomatis & Metode STAR**: Analisis jawaban berdasarkan 6 kriteria utama, pendeteksian komponen STAR (Situation, Task, Action, Result), dan pemberian contoh jawaban yang disempurnakan.
- **Dashboard Perkembangan & Metrics**: Visualisasi radar chart & line chart untuk memantau perkembangan nilai dari waktu ke waktu.
- **Bank Pertanyaan Interaktif**: Koleksi 100+ pertanyaan interview lengkap dengan petunjuk HR, kriteria penilaian, dan contoh jawaban.
- **Artikel & Tips Interview**: Panduan komprehensif menghadapi interview HR, User, Teknis, Behavioral, hingga bahasa Inggris.
- **Panel Admin Full-Featured**: Pengelolaan bidang, posisi, pertanyaan, artikel, pengguna, dan monitoring sesi simulasi.

---

## 🛠️ Teknologi yang Digunakan

- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS, Lucide Icons, Recharts, Framer Motion.
- **Backend / Database**: Supabase & PostgreSQL (dilengkapi Client Fallback Mock Engine untuk eksekusi instant).
- **AI & Rule Engine**: Custom heuristic & NLP keyword evaluation engine dengan dukungan STAR framework parser.

## 🚀 Panduan Instalasi & Pengoperasian

### 1. Prasyarat
- Node.js >= 18.x
- npm / yarn / pnpm

### 2. Langkah Instalasi

```bash
# Clone atau masuk ke direktori proyek
cd interview-ready

# Install dependensi
npm install

# Jalankan server pengembangan
npm run dev
```

Buka browser dan akses [http://localhost:3000](http://localhost:3000).

### 3. Build Produksi

```bash
npm run build
npm run start
```
